# Why the response-review desk has no front end

A manager's Monday work is to read the low scores, compare branches, assign follow-ups and record what changed. That work fits a database and a coding agent. Read-only HTML gives the team a scorecard, a recovery queue and a record-review list. It can be printed and shared after the appropriate information checks.

This build does not collect responses from customers. Keep the existing survey collection service, or connect a separately tested form. It has no mobile app, offline capture, drag and drop survey designer, respondent login, automated distribution or live CRM sync. Those features matter to collection and must be planned before replacing a full Salesforce Feedback Management deployment.

The free desk fits an operator who has response exports and wants the records and follow-up process under their control. The database can run locally in PGlite or on PostgreSQL. Claude Code, Codex, OpenCode and Cursor can all use the same commands. The agent is an interface, not a storage format.

Omni by Enterprise DNA can add the team's collection forms, connections and read-only screens, then operate the resulting system. One setup fee, then a retainer. Scope those additions against the real workflow before making a switch.
